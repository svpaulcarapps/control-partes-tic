Control TIC se ejecuta dentro de la app instalada. La interfaz es pública; las operaciones de datos necesitan una sesión autenticada del responsable, emitida por Google y válida durante 30 días. Los datos se consultan a través del servicio de Compendio y no se guardan en la caché offline. El botón Avisos permite activar, probar y desactivar las notificaciones del dispositivo.

Cerrar sesión revoca la sesión firmada en el servidor y la elimina del dispositivo.
