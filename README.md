# Control de Partes TIC

Aplicación instalable del Colegio San Vicente de Paúl, Cartagena. Usa el mismo icono en el panel, la pantalla de inicio y los avisos.

Al abrir la dirección principal se accede directamente al panel, sin portada. La instalación y los avisos se configuran desde `?ajustes=1` o desde «App y avisos» dentro del panel.

El panel de gestión continúa en Google Apps Script y conserva sus permisos de Google. GitHub aloja la interfaz de acceso y los archivos de instalación; no contiene datos de incidencias, correos, claves privadas ni credenciales.

Las notificaciones requieren abrir el panel con la cuenta del responsable TIC y activar los avisos en cada dispositivo. En iPhone/iPad hay que añadir antes la app a la pantalla de inicio desde Safari. Los avisos son genéricos y no incluyen datos de profesores o incidencias.

El envío del formulario registra un evento firmado en el servicio de notificaciones. Suscripciones y entregas TIC están separadas de las de Sustituciones. No se utiliza WhatsApp ni CallMeBot.
